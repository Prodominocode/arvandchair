# مستندات پروژه — پلتفرم مبلمان اداری (فروشگاه + Portfolio + CRM + باشگاه مشتریان)

این مجموعه، بسته‌ی کامل مستندات پیش از شروع Vibe Coding است. ترتیب استفاده:

> **نکته:** ترتیب فازها در `01-workflow-roadmap.md` **UI-first** است — اول کل UI/UX سایت صفحه‌به‌صفحه با داده‌ی Mock ساخته می‌شود (فاز ۳)، بعد مدل داده با دقت نهایی می‌شود (فاز ۴). به همین دلیل `02-data-model.md` فعلاً «Draft v1» است، نه Schema قطعی.

## نحوه‌ی شروع کار

1. این بسته (`README` + فایل‌های `00` تا `07`، جمعاً ۹ فایل) را در پوشه‌ی `/docs` ریشه‌ی ریپازیتوری پروژه‌ات کپی کن؛ پوشه‌ی `assets/brand/` (شامل لوگو) را هم همراهش ببر.
2. Claude Code (یا هر ابزار AI Coding دیگر) را در همان ریپو باز کن و **پرامپت Bootstrap** (بخش ۰ در `07-execution-playbook.md`) را به‌عنوان اولین پیام بفرست — از AI می‌خواهد کل پوشه‌ی `docs/` را بخواند، از جمله `04-master-scenario-prompt.md` که قوانین ثابت پروژه است؛ دیگر لازم نیست محتوای آن را جدا Copy-Paste کنی.
3. برای اجرای دقیق هر فاز — الگوی Closeout فاز ۰، Kickoff فاز ۱ و بعد — **`07-execution-playbook.md`** را دنبال کن.
4. فاز ۰ عملاً تکمیل است (زبان‌ها، دسته‌ها، پرسونا، برند مشخص شده‌اند)؛ فقط موارد «هنوز باز» زیر باقی مانده.
