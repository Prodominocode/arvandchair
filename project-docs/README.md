## نحوه‌ی شروع کار

1. این بسته (`README` + فایل‌های `00` تا `07`، جمعاً ۹ فایل) را در پوشه‌ی `/docs` ریشه‌ی ریپازیتوری پروژه‌ات کپی کن؛ پوشه‌ی `assets/brand/` (شامل لوگو) را هم همراهش ببر.
2. محتوای `04-master-scenario-prompt.md` (بخش بین `START PROMPT` و `END PROMPT`) را به‌عنوان اولین پیام به Claude Code (یا هر ابزار AI Coding دیگر) بده.
3. برای اجرای دقیق هر فاز — چطور Kickoff کنی، بازبینی کنی، و Closeout بگیری — **`07-execution-playbook.md`** را دنبال کن؛ همان‌جا الگوهای آماده‌ی پرامپت هست.
4. فاز ۰ عملاً تکمیل است (زبان‌ها، دسته‌ها، پرسونا، برند مشخص شده‌اند)؛ فقط موارد «هنوز باز» زیر باقی مانده. می‌توانی مستقیم با گام Closeout فاز ۰ (طبق `07-execution-playbook.md`) شروع کنی.

## وضعیت تصمیمات فاز ۰

**تعیین‌شده:**
- ✅ زبان‌ها: فارسی (پیش‌فرض/بدون پیشوند)، انگلیسی (`/en`)، عربی (`/ar`) — فعال‌سازی en/ar تدریجی
- ✅ دسته‌بندی اولیه: صندلی، میز، مبلمان اداری، آمفی‌تئاتر، همایش و سینما (داینامیک از پنل)
- ✅ پرسونا: اولویت اول B2B سازمانی، اولویت دوم B2C خرد
- ✅ کتابخانه‌های موشن/سه‌بعدی: استفاده‌ی محدود و هدفمند، نه سراسری (GSAP > Framer Motion > R3F)
- ✅ جغرافیای فروش: فعلاً فقط ایران (بدون صادرات فعلی؛ زبان عربی ربطی به این تصمیم ندارد)
- ✅ مدل قیمت: ترکیبی — `direct-purchase` عمومی، `quote-only` بدون نمایش قیمت، بدون قفل ورود برای دیدن قیمت
- ✅ حساب کاربری B2B: تک‌کاربره برای MVP، چندکاربره/نقش‌ها → Backlog نسخه‌ی بعد
- ✅ برند: نام «اروند»، لوگو، و پالت رنگ دریافت شد (جزئیات در `06-design-tokens.md`)
